# Project skills

Copied from [emilkowalski/skills](https://github.com/emilkowalski/skills) at commit 2d22863 (MIT, see
`LICENSE-emilkowalski-skills`). Only the ones that apply to this web landing page are included:

| Skill | Use it to |
|---|---|
| `break-ui` | Stress the page with worst-case content (long French labels, huge FCFA totals, odd pasted links) |
| `mobile-native` | Make the site feel native on Android phones (tap states, safe areas, input zoom) |
| `review-animations` | Critique existing motion against a strict craft bar |
| `improve-animations` | Audit all motion code and write prioritized fix plans |
| `find-animation-opportunities` | Propose (read-only) where motion would help, with exact values |
| `animation-performance` | Keep animations in the frame budget on slow phones |
| `emil-design-eng` | General UI polish principles |
| `animation-vocabulary` | Name a motion effect from a vague description |

To update: `npx skills@latest add emilkowalski/skills`, or copy the folders again from the repo.
